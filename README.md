## 📖 Overview
**CloudCast** is a lightweight weather utility that provides instant meteorological data. Built with a focus on speed and simplicity, it delivers real-time updates without the overhead of heavy frameworks.

- **Fast:** Pure JavaScript for instant DOM updates.
- **Sleek:** Utility-first styling with Tailwind CSS.
- **Secure:** Environment-ready configuration for API keys.

---

## ✨ Features
- 🔍 **City Search:** Real-time data for global locations.
- 🌡️ **Live Metrics:** Temperature, Humidity, and Wind Speed.
- 💾 **Cached Results:** Optimized search using local storage.

---

## 🛠️ Tech Stack
- **Logic:** JavaScript (ES6+)
- **Styling:** Tailwind CSS 
- **API:** OpenWeatherMap API
- **Environment:** Dotenv for API security
